# What Is Docs-as-code?

<div style='position: relative; padding-bottom: 56.25%; height: 0;'><iframe src='https://player.viloud.tv/embed/video/82cba7ea62883a559baee3e4f0eaa573?autoplay=0&volume=1&controls=1&title=1&share=1&open_playlist=0' style='position: absolute; top: 0; left: 0; width: 100%; height: 100%;' frameborder='0' allow='autoplay' allowfullscreen></iframe></div>

Docs-as-code is a technical writing environment where the technical writer uses the same tools as the software developers. When documenting softwares, this eases the reviewing process and increases the collaboration possibilities.

## Benefits

When using Docs-as-code with Markdown compared with DITA, includes the following benefits:

* Smoother and faster reviewing process.
* Flexibility when working with information layout.
* Installing add-ons to make the documentation into a product.

### Add-ons To Integrate

The following add-ons are great extensions to the docs-as-code environment:

* Litlyx
    * Litlyx is a Traffic Analytics site from Italy, Europe. The installation process is quick and the product is GDPR compliant. See [Litlyx webpage](https://litlyx.com/) for more information.
* Swagger
    * Swagger is an API preview documentation tool. The tool provides example requests and example of a return object. See [Swagger webpage](https://swagger.io/) for more information.
* GitLens
    * GitLens is a git viewing tool. This tool visualizes the git branches and provides insights to the git history. 
    * GitLens is especially helpful when new to git. See [GitLens wepage](https://www.gitkraken.com/gitlens) for more information.
