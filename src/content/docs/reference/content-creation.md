My favourite assingment in Lower secondary school was when we were asked to create our own newspaper or magazine. It made me realise how much I love writing.

When I later was applying to Upper Secondary School, I applied to Social Science with a distinct in media studies. To presume a career as a sports journalist.

The dream faded away when I realised that journalist have to write articles they don´t want to and scoops that might create conflicts.

15 years later I applied to a online school for beginners in technical writing named Technical Writing Head Quarter (TWHQ). I immidiately fell in love it. This way I could write about technical subjects and focus on understandability and create clarity instead of drama.

### The SportsDB API Docs

Once I again I touched the topic — Sports.

But here I touch another topic dear to my and that is technology.

Before joining TWHQ I worked as a system developer for 10 years. When I worked with developing systems and creating integrations, It made my day if the API-docs contained the following:

- Ease to find the different API Calls and their possibilities.
- How to quickly integrate with it to know what kind of data I can expect.
- What to do if I get an error code.

When my task in TWHQ was to write a API documentation, I knew straight away how I would design it.

This particular API I have integrated with a lot during my years in software developing. I used this API when learning a new framework and used the data from theSportsDB to quickly set up a web application in sports.

With the API-documentation I wrote, I am displaying my ability to write documentation to other developers by speaking in their language.
